### 🐦 [BirdCLEF 2026](https://github.com/parijain1705/birdclef-2026)
Bird sound recognition using deep learning. Audio is converted into **mel spectrograms** and classified with a neural network, turning a sound problem into an image-style problem. Built for the BirdCLEF bioacoustics challenge.
`Python` `Deep Learning` `Audio Processing` `Mel Spectrograms`

### 🤖 [AutoStream Agent](https://github.com/parijain1705/autostream-agent)
An agentic AI chatbot built with **LangGraph** and **Groq**. It simulates a real-world social-to-lead conversion workflow for a fictional SaaS company, so a casual chat can turn into a qualified lead.
`Python` `LangGraph` `Groq` `Agentic AI`

### 🩺 [Disease Prediction](https://github.com/parijain1705/Disease-Prediction)
A machine learning project that predicts diseases from input data, applying ML to a real-world healthcare use case.
`Python` `Machine Learning`
